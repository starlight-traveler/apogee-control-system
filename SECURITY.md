# Safety And Security

This repository contains flight-control software for a physical vehicle. Do not treat builds from an arbitrary branch as launch-ready.

Report issues that could affect estimator behavior, apogee prediction, actuation, sensor frames, units, calibration, runtime settings, or log decoding with a clear safety-impact note. If an issue should not be public yet, share it directly with the maintainers before opening a public issue.

Before flight use, independently review the change, run replay validation, and perform bench or hardware-in-the-loop checks appropriate to the affected subsystem.
