# Replay Data

This directory is the local staging area for decoded flight logs, replay CSV output, event JSON, spreadsheets, and scratch analysis data.

Most files here are intentionally ignored:

- raw binary logs (`*.BIN`, `*.bin`)
- decoded/generated CSVs (`*.csv`)
- spreadsheets (`*.xlsx`)
- replay event dumps and large local artifacts

Commit only small, intentional documentation files from this directory. If a dataset must be shared, document where it came from and why it is small enough or curated enough to belong in Git.
