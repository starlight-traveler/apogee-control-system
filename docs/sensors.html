Sensor rails

Fresh, framed, and matched.

The sensor code has one recurring theme: a number is not useful until the firmware knows when it was measured, which frame it is in, and whether it belongs with the selected attitude source.

Rail explorer

Click a rail

BMP585 and MS5611

BMP585 is the primary altitude source. Fresh finite altitude is required for pad reference, AGL use, baro liftoff backup, and baro/state agreement gates. MS5611 is a secondary pressure rail for comparison and diagnostics.

ICM20948

Fast accel/gyro rail with optional DMP quaternion. If ICM attitude is selected, fresh ICM accel is preferred so attitude and acceleration share the same frame errors.

LSM9DS1

Independent fast rail with accel, gyro, mag, and a phase-aware observer. If LSM attitude is selected, fresh LSM accel is preferred. Mag and accel correction are gated by phase and trust.

BNO055 / BNO085

Reference attitude rail. BNO can trim coast attitude only after fresh post-burnout samples, tilt agreement, minimum sample count, and a ramped blend. It should not override the fast rails abruptly.

Ellipse / Pulse20

Optional high-quality sidecar IMU parsed through the SBG serial protocol. It publishes raw IMU and mag into ACS body frame, with bounded serial service so it cannot starve the flight loop.

WT901

Comparison rail. Its values are converted into body-frame m/s^2, rad/s, YPR, and quaternion diagnostics so frame mistakes and rail disagreement can be seen in replay plots.

Frame contract

Body axes

Body +Z

Rocket vertical/up axis when on the pad. Static gravity checks should show dominant +Z after mount rotation.

Body +X / +Y

Lateral axes used for tilt, horizontal speed seed, and frame comparison. Sign mistakes here become false zenith and bad AoA.

Quaternion wxyz

All quaternion math uses w, x, y, z order. The code normalizes and validates quaternions before using them as attitude truth.

Freshness rules

Why it matters
  • 01Cached sensor values may be logged for continuity, but phase transitions should use fresh evidence.
  • 02Baro AGL is valid only when pad reference exists and the current baro sample is fresh and finite.
  • 03Quaternion freshness and accel freshness are checked independently because they can update at different rates.
  • 04Cross-check trust lets one rail reduce another rail's correction authority without deleting the data from logs.
