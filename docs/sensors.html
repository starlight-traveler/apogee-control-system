Sensor rails

Sensor frames and freshness.

The sensor code has one recurring theme: a number is not useful until the firmware knows when it was measured, which frame it is in, and whether it belongs with the selected attitude source.

Rail explorer

Click a rail

BMP585 and MS5611

BMP585 is the primary altitude source. Fresh finite altitude is required for pad reference, AGL use, baro liftoff backup, and baro/state agreement gates. MS5611 is a secondary pressure rail for comparison and diagnostics.

ICM20948

Fast accel/gyro rail with optional DMP quaternion. If ICM attitude is selected, fresh ICM accel is preferred so attitude and acceleration share the same frame errors.

LSM9DS1

Independent fast rail with accel, gyro, mag, and a phase-aware observer. If LSM attitude is selected, fresh LSM accel is preferred. Mag and accel correction are gated by phase and trust.

BNO055 / BNO085

Reference attitude rail. BNO can trim coast attitude only after fresh post-burnout samples, tilt agreement, minimum sample count, and a ramped blend. It should not override the fast rails abruptly.

Ellipse / Pulse20

Optional high-quality sidecar IMU parsed through the SBG serial protocol. It publishes raw IMU and mag into ACS body frame, with bounded serial service so it cannot starve the flight loop.

WT901

Comparison rail. Its values are converted into body-frame m/s^2, rad/s, YPR, and quaternion diagnostics so frame mistakes and rail disagreement can be seen in replay plots.

Frame contract

Body axes

Body +Z

Rocket vertical/up axis when on the pad. Static gravity checks should show dominant +Z after mount rotation.

Body +X / +Y

Lateral axes used for tilt, horizontal speed seed, and frame comparison. Sign mistakes here become false zenith and bad AoA.

Quaternion wxyz

All quaternion math uses w, x, y, z order. The code normalizes and validates quaternions before using them as attitude truth.

Sensor math

Corrections

Every sensor rail is corrected before the estimator uses it. The important corrections are pressure-to-altitude conversion, mount-frame rotation, quaternion normalization, gravity removal, and stale/spike rejection.

Baro altitude

\(h = 44330\left(1 - (p/p_0)^{0.190294957}\right)\)

BMP585 pressure is converted to altitude with the configured sea-level pressure reference. The code then converts meters to feet for logging and back to meters where the estimator expects SI.

Mount rotation

\(\vec{a}_{body} = R_{mount}\vec{a}_{sensor}\)

ICM, LSM, BNO, WT901, and Pulse values are all rotated into the rocket body frame before comparisons. A sign error here becomes bad zenith and bad AoA.

Quaternion basis rotation

\(R_{body} = R_{mount}R_{sensor}R_{mount}^{T}\)

Vector samples can be multiplied once by the mount matrix. Quaternion samples are converted through a rotation matrix so the attitude basis changes correctly.

Gravity and linear accel

\(\vec{a}_{linear} = \vec{a}_{measured} - R(q)\vec{g}\)

Static acceleration includes gravity. The attitude path tells the estimator where gravity points so linear motion is not confused with tilt.

Correction gates

Trust rules
baro

Fresh finite altitude

Pad reference and AGL-dependent gates require a current finite barometer sample. Cached altitude can be logged, but it cannot create liftoff or actuation evidence.

spike

Pressure jump rejection

The BMP585 path rejects altitude jumps that imply more than the configured maximum altitude rate, with a minimum jump allowance so normal noise is not over-filtered.

rail

Matched attitude and accel

Selected ICM attitude uses fresh ICM accel when available; selected LSM attitude uses fresh LSM accel. Blended/default attitude uses the normal fresh-rail preference.

blend

Reference correction is ramped

BNO/Pulse reference attitude can trim the fast rails only after freshness, tilt agreement, sample count, phase, and ramp checks pass.

Freshness rules

Why it matters
  • 01Cached sensor values may be logged for continuity, but phase transitions should use fresh evidence.
  • 02Baro AGL is valid only when pad reference exists and the current baro sample is fresh and finite.
  • 03Quaternion freshness and accel freshness are checked independently because they can update at different rates.
  • 04Cross-check trust lets one rail reduce another rail's correction authority without deleting the data from logs.
