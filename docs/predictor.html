Apogee model

One coast rollout, many guardrails.

The predictor takes a compact coast seed and rolls it forward until vertical velocity reaches zero. The implementation is practical rather than magical: bounded inputs, CFD interpolation, density scaling, actuator lag, RK integration, and flags whenever the answer leaves trusted ground.

Not flight math

This small calculator is intentionally simplified. It shows the direction of the effects: higher vertical speed raises apogee, flap angle increases drag, and tilt makes the rollout less clean. The firmware model is more detailed and uses CFD table forces.

Real predictor pipeline

Firmware path
seed

Sanitize state

Use raw vertical Kalman altitude and velocity, clamp zenith and angular rate, and use horizontal speed only when attitude and accel are fresh enough.

air

Build air-relative state

Subtract wind, compute local temperature, density ratio, speed of sound, Mach, and relative velocity angle.

cfd

Interpolate force table

Look up axial and normal force by flap angle, angle of attack, and Mach. Out-of-table values clamp and raise flags.

force

Project forces

Scale by density and learned drag, rotate axial/normal forces into vertical/horizontal axes, add gravity, and compute pitch moment.

roll

Integrate to apogee

RK4 advances state until vertical velocity crosses zero. The last bracket is refined so apogee is not the first descending sample.

Uncertainty behavior

Control safety

Step limit

When the integration cap is hit while still climbing, the returned value is only a conservative telemetry bound. The prediction is flagged uncertain so control should retract rather than trust it.

High AoA fallback

If AoA is above CFD coverage, the table edge can be too drag-heavy. Telemetry can blend toward a low-drag bound, but the model still marks the result uncertain.

Wide bounds

Drag perturbation bounds are not a formal confidence interval. They are a sensitivity test: if small drag changes move apogee a lot, the command should be conservative.

Adaptive drag

Drag learning happens only in clean coast when the flaps are settled and predictor seed flags are healthy. Learning from bad input would make future predictions worse.
